# 课堂点名积分榜 —— 部署与使用说明（集成在 mysite 容器）

访问地址
- 公网：https://www.liufeisheng.cn/classroom/
- 局域网：http://群晖IP:8084/classroom/
- 首页入口：网站首页“推荐网站”区已加“课堂点名积分榜”卡片。

架构（B2 方案）
- 作为 Django 应用 `classroom` 集成进现有 mysite 项目，未新增容器、端口或域名。
- 数据独立存储在 `classroom.sqlite`（与主站 MongoDB 完全隔离）。
- 通过 `classroom/db_router.py` 让 classroom 应用只读写该 SQLite。
- 写操作（建班、加减分、导入、删除、恢复）必须带管理口令；看榜免口令。

管理口令
- 已生成在 `.env` 文件中（CLASSROOM_TOKEN 开头为 Fy）。
- 页面首次写操作时会弹框要求输入口令，输入后本会话记住。
- 如需更换：修改 `.env` 中的 CLASSROOM_TOKEN，然后重启容器。

容器重启 / 建表
- docker-compose.yml 的启动命令已改为：
  先执行 `migrate classroom --database=classroom`，再启动 Django。
- 因此容器每次重启都会自动确保 classroom 库表最新，无需手动命令。

备份与恢复
- 核心数据文件：mysite/classroom.sqlite（一个文件）。建议用 Hyper Backup 备份 mysite 目录。
- 页面内也可：班级管理 → 导出全部班级备份（JSON）；换机或异常时用“恢复全部班级备份”。
- 升级前已在 NAS 上留有 mysite_backup_ 开头的整站备份。

使用要点
1. 点“班级管理”新建班级（已示范“人工智能2401班”），可建多个班，下拉切换，数据各自独立。
2. “导入名单”上传 Excel（首行表头，含“姓名”列；“学号”列可选），已实测55人完整显示。
3. 随机滚动点名：滑块调速度，1/2/5/10 选择单次加减分值，停止后对该学生加/减分。
4. 搜索框输入姓名可直接给该学生加/减指定分；撤销按钮可回退最后一步。
5. 前三名上台并显示头衔；专业填“人工智能基础”时默认 AI大模型/算法大师/智能新锐，也可在设置里自定义。

需要注意：HTTPS 证书已过期
- 当前 www.liufeisheng.cn 的泛域名证书（Let's Encrypt）在 2026-03-22 已到期，
  浏览器会提示“不安全”，但功能不受影响（已在忽略证书的情况下验证全部接口正常）。
- 续签方法（1Panel）：
  1) 登录 1Panel 面板 → 网站 → 证书（或“网站/SSL”）；
  2) 找到 *.liufeisheng.cn 证书，点“续签/续期”（Let's Encrypt 通常可自动续签）；
  3) 若自动续签失败，检查该站点的 ACME 申请方式、80 端口/HTTP 校验路径是否被反代占用，
     重新执行一次申请；
  4) 续签成功后，确认对应站点已勾选使用该新证书，再强刷浏览器验证。
- 建议在 1Panel 里开启证书“自动续期”，避免再次过期。
